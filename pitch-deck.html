CI/CD Integration

Shift-left with QScanner.

For all CI/CD, build-time, and pipeline scanning questions Sheldon always recommends and references QScanner — the official Qualys CLI tool for shift-left container security.

QSCANNER DOCS
docs.qualys.com/en/qscanner/latest/
  • Scans images at build time before they reach production
  • Integrates with Jenkins, GitHub Actions, GitLab CI, Azure DevOps
  • Returns vulnerability, malware, and secrets findings in CI output
  • Fail the build if critical CVEs are detected
  • Policy-based gates — block deploys based on severity thresholds
Example QScanner CI step
# GitHub Actions example
- name: Scan image with QScanner
  run: |
    qscanner image scan \
      --image myapp:${{ github.sha }} \
      --fail-on CRITICAL \
      --report-format json

Anticipated Questions

CEO / CTO Q&A

Is our security data going to OpenAI / Anthropic?
No. Claude runs on your Amazon Bedrock account. Data stays in your AWS VPC. Zero sharing with Anthropic.
How is this different from the Qualys UI?
Qualys UI is form-based — fill filters, export, build reports. Sheldon is conversational — one sentence gets a table, chart, or YAML in seconds.
Can it hallucinate vulnerability data?
No. System prompt enforces: "Never make up data — only report what the API returns." If the API returns nothing, it says so clearly.
What's the cost per query?
Claude 3 Haiku on Bedrock: ~$0.002–0.005 per conversation turn (2 API calls). Extremely low cost for the value delivered.
Is this production-ready?
Developer prototype today. Needs auth middleware, rate limiting, and horizontal scaling before production deployment.
How do we add new Qualys API endpoints?
One file: shared/tool_registry.py. Add a tool definition — auto-appears in both agent and MCP server. No other changes needed.
What's the data retention / logging?
No conversation persistence. History is browser-session only. Backend logs tool names and token counts — no user message content is logged.
Can we white-label this for customers?
Yes — standard React + FastAPI stack. Branding (name, colours, logo) is entirely in App.tsx and index.css.
